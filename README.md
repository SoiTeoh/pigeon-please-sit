# Pigeon Please Sit

一个关于“鸽子什么东西都想坐一下”的搞笑物理小游戏草稿。

## 灵感来源

灵感来自一个真实短视频：

一只鸽子看到地面上的小喷泉后，直接把屁股坐到了喷水口上。

最有意思的地方并不是喷泉本身，而是：

**鸽子把一个原本不是座位的东西，非常认真地当成了座位。**

因此这个项目的核心概念是：

> 这东西也能坐？

## 核心玩法

玩家控制鸽子移动、起跳，并尝试让鸽子的屁股精准落在目标物体上。

第一关可以直接从“小喷泉”开始。

例如：

鸽子  
↓  
蓄力  
↓  
起跳  
↓  
调整落点  
↓  
屁股落到喷泉上  
↓  
根据精准程度评分

玩家不是单纯跳到目标上，而是需要尽可能准确地“坐”到目标位置。

## 第一版 MVP

第一版只需要做：

- 一个简单城市地面场景
- 一只简化鸽子
- 一个小喷泉目标
- 左右移动
- 长按蓄力
- 松手起跳
- 简单抛物线运动
- 空中轻微修正
- 落点检测
- 判断是否成功“坐下”
- 根据落点精准度评分
- 成功动画
- 失败动画
- 重新挑战

## 评分逻辑

可以先分成：

### Perfect

屁股精准落在目标中心。

显示：

`精准入座！`

### Good

位置稍微偏离，但成功坐住。

显示：

`有点硌，但能坐。`

### Miss

踩空、撞到边缘或没有正确坐到目标。

显示：

`这不是这么坐的！`

- 消防栓
- 共享单车车座
- 路桩
- 路牌
- 雕像头顶
- 汽车后视镜
- 喷泉雕塑
- 雨伞尖
- 另一只鸽子

未来可以逐渐发展成：

**寻找城市中最离谱的座位。**

## 当前目标

先让 Codex 完成一个只有“小喷泉”目标的单关卡原型。

主要验证：

**控制鸽子跳起来并精准用屁股坐到目标上，这个动作本身是否有趣。**

如果这个核心动作好玩，再考虑增加更多场景和目标。
